For Page 1 make these new measure before making the dashboard.

1. Average Fraud Amount = CALCULATE(AVERAGE('Dataset'[amount]),'Dataset'[isFraud]=1)
2. Fraud Amount = CALCULATE(SUM('Dataset'[amount]),'Dataset'[isFraud]=1)
3. Fraud Rate = DIVIDE([Fraudulent Transactions],[Total Transactions],0)
4. Fraud Rate by Type = DIVIDE([Fraudulent Transactions],[Total Transactions],0)
5. Fraudulent Transactions = CALCULATE(COUNTROWS('Dataset'),'Dataset'[isFraud]=1)
6. Highest Fraud Amount = CALCULATE(MAX('Dataset'[amount]),'Dataset'[isFraud]=1)
7. Total Transaction Amount = SUM('Dataset'[amount])
8. Total Transactions = COUNTROWS('Dataset')
9. Transaction Status = IF('Dataset'[isFraud]=1,"Fraud","Genuine")
